# Deadlock Intelligence: план и договорённости

Перенесено из чата в браузерной версии Claude (2026-11-20) и сверено с проектом.
Обновляй этот файл, когда что-то сделано или решено.

## 1. Цель

Сайт со статистикой Deadlock уровня statlocker.gg / lockblaze.com, а затем лучше них. Нужен настоящий продакшн, а не демо.

- Тёмный игровой стиль: плоский и плотный, без градиентов и свечения, без «ИИшного» вида.
- Вход через Steam (кнопка «My profile»), своя БД и кэш.
- Много языков, потому что аудитория международная.
- Репозиторий: `un18716197159/deadlocktracker`. Прод: https://deadlocktracker.vercel.app
- Цель продукта: широкая аудитория и при этом качество. Для этого важны ключ API (лимиты), скорость и SEO.

## 2. Технологии

- **Next.js 16.4.3**: App Router, Turbopack, Cache Components (`"use cache"`, `cacheLife`). Перед кодом читать доки в `node_modules/next/dist/docs/` (см. AGENTS.md).
- React Server/Client components, TypeScript, Tailwind v4 и собственные CSS-файлы. Шрифты Geist (latin, latin-ext, cyrillic).
- **Данные:** Deadlock API `api.deadlock-api.com`, заголовок `X-API-KEY`, если ключ задан (пока его нет, лимиты считаются по IP).
  - `/v1/assets/{heroes,items,ranks,ranked-seasons}`
  - `/v1/players/{steam,rank,hero-stats,steam-search,match-history}`
  - `/v1/leaderboard/{region}`
  - `/v1/analytics/*`: hero-stats, item-stats, hero-counter-stats, hero-synergy-stats
  - `/v1/builds`, `/v1/matches/metadata`
  - Фильтр рангов: `min_average_badge` / `max_average_badge`
- **БД:** Neon Postgres и Drizzle ORM (`drizzle-orm/neon-http`). Таблицы `users`, `cache_entries`, `favorites`. Создание: `npm run db:push`, запасной вариант — SQL из `db/schema.sql`.
- **Кэш:** `cachedUpstream(key, ttl, load)` в БД. При ошибке API отдаёт старые данные. TTL: ассеты сутки, поиск и лидерборд 10 минут, игрок 2 минуты, аналитика 10 минут, остальное 5 минут.
- **Вход:** Steam OpenID. `account_id = SteamID64 − 76561197960265728`. Cookie `dt_session`: подписанный JWT (jose, HS256) на 30 дней, ключ `SESSION_SECRET` (не короче 32 символов).
- **Иконки предметов:** `public/item-icons/<slug>.webp`. slug — имя в нижнем регистре, где всё, кроме букв и цифр, заменено на `-`. Загрузка: `npm run icons:sync`, спокойно и с паузами. Есть ли иконка, определяется по `onError` в `ItemArt`.
- **Переменные окружения:** `DATABASE_URL`, `SESSION_SECRET`, `DEADLOCK_API_KEY` (необязательная), `NEXT_PUBLIC_SITE_URL`.

## 3. Структура и дизайн

- Навигация `src/app/components/app-shell.tsx`: логотип-квадрат «D», Heroes, Tier list, Items, Builds, Matches, Leaderboards, Compare, переключатель языка, кнопка Steam (после входа аватар с меню My profile / Sign out). В подвале юридическая строка (неофициальный проект, © Valve, ссылка на deadlock.gs) и ссылка на `/privacy`.
- CSS идёт слоями: globals → heroes → items → leaderboards → visual-system → shell → polish → theme → **flat**. Последний слой `flat.css` задаёт нейтральную тёмную палитру: фон `#0e1015`, акцент `#7c6cf0`. Страничные стили перебиваются префиксом `.app-shell`.
- Слоты предметов: оружие `#e69a3c`, живучесть `#7fbd5a`, дух `#b98bf0`.
- Команды (`src/lib/teams.ts`): 0 = The Hidden King (янтарный `#f0b254`), 1 = The Archmother (синий `#6fb5ff`). **Это предположение, на реальных матчах не проверено.**

## 4. Что сделано

- **Главная:** «Deadlock stats», живой поиск игроков (Ctrl+K), избранные и недавние игроки, «Мета сейчас» (топ-8 героев по винрейту), плитки разделов.
- **Лидерборд:** разбор неоднозначных записей сначала по нику в Steam, потом через поиск игроков (для верхних 40). У части нижних мест ник может остаться без ссылки.
- **Билды:** иконки берутся из всех предметов, названия на выбранном языке.
- **Герой `/heroes/[id]`:** баннер в стиле вики, роль, винрейт и пикрейт, способности (Active/Passive, свойства, апгрейды, без «Melee»), лучшие предметы, контрпики и синергии (показываются, только если поля найдены), лор, ссылки. Описания рендерятся безопасно через `src/lib/rich-text.tsx`.
- **Предмет:** крупная иконка, слот, тир, цена, описание, статистика и разбивка по героям.
- **Профиль игрока:** шапка с аватаром и рангом, статистика, «Форма» (последние 20 матчей, график KDA, серия и т.д.), герои с винрейтом, матчи, кнопка «В избранное».
- **Матчи:** компактный список с фильтрами и поиском по ID. На странице матча сводка по командам с полосками.
- **Сравнение:** метрики с полосками и подсветкой лучшего.
- **Тир-лист `/tier-list`:** S/A/B/C/D по винрейту с бонусом за популярность (перцентили 10/20/30/25/15%), фильтр рангов, таблица.
- **i18n:** 12 языков (en, ru, uk, es, pt, de, fr, tr, pl, zh, ja, ko), реализация в `src/lib/i18n/*`. Язык хранится в localStorage и cookie `dt_lang`. Первый показ идёт на английском. Переводы носители не проверяли. Названия из API запрашиваются на выбранном языке (имена в стиле Steam: russian, schinese, koreana, brazilian…), на живом API не проверено, при отказе откат на английский.
- **Избранное:** `/api/favorites` (GET/POST/DELETE), лимит 50.
- **Прочее:** `/privacy`, sitemap и robots, README, dev-роуты `/api/debug/item` и `/api/debug/shape` (в продакшене выключены).

## 6. Договорённости и ограничения

- **Секреты** (`DATABASE_URL`, `SESSION_SECRET`, `DEADLOCK_API_KEY`, содержимое `.env*`): не выводить, не просить присылать в чат, не коммитить. Пользователь вставляет их в файл сам, Claude говорит, куда именно.
- **Данные:** не парсить deadlock.gs массово. Арт предметов принадлежит Valve, подпись есть в подвале. Фото публичных людей не использовать.
- **Файлы пользователя:** перед правкой смотреть актуальный файл и не затирать данные. Не возвращать устаревающие списки вроде `item-icons.json`.
- **Проверка типов:** обязательно смотреть ошибки неопределённых имён (так однажды проскочило `heroPortrait is not defined`).
- **Стиль работы:** маленькие понятные шаги. После каждого шага коротко рассказать, что изменилось и что проверить. Claude Code правит файлы прямо в `D:\VScode\трекер`, архивы больше не нужны. Коммит и пуш только по просьбе пользователя.
- **Пользователь:** новичок, говорит по-русски и неформально. Объяснять простыми словами и делать за него.
