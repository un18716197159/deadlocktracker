# Deadlock Intelligence

Полный план, что сделано и что осталось: @docs/plan.md. Обновляй его, когда шаг готов.

## Главные правила

- Отвечай по-русски, простыми словами и по шагам: пользователь новичок.
- **Секреты** (`DATABASE_URL`, `SESSION_SECRET`, `DEADLOCK_API_KEY`, содержимое `.env*`) никогда не выводи в чат, не проси прислать и не коммить. Если нужно значение, попроси пользователя вставить его в файл самому и скажи, куда. Проверяй, что значение заполнено, не печатая его.
- Перед правкой читай актуальный файл и не затирай данные пользователя.
- Маленькие шаги. После каждого коротко рассказывай, что изменилось и что проверить.
- Коммит и пуш только по просьбе пользователя.
- Дизайн: плоский, плотный, тёмный (как Statlocker), без градиентов и свечения.
- Не парси deadlock.gs массово.
- Next.js 16 с Cache Components: перед кодом читай доки в `node_modules/next/dist/docs/`.
- При проверке типов смотри и ошибки неопределённых имён.

## Команды

- `npm run dev` запускает сайт на http://localhost:3000
- `npm run build` собирает сайт для продакшена
- `npm run db:push` создаёт или обновляет таблицы в Neon
- `npm run icons:sync` загружает иконки предметов (спокойно, с паузами)
